# Tako — tako.danielpro.dev

Site estático do Tako, o gestor de finanças pessoais do Daniel Marcos.

- Endereço: https://tako.danielpro.dev
- Subdomínio em `danielpro-site.json`: `tako`
- Língua por defeito: português (Moçambique), com inglês no mesmo endereço
- Tema claro e escuro, a seguir a `prefers-color-scheme` e a lembrar a escolha

O instalador Windows aponta para `/downloads/Tako-1.2.0-x64-Setup.exe`. O ficheiro `.exe` não vai no git. Tem de existir nesse caminho no servidor para o botão descarregar a versão 1.2.0.

O botão «Entrar na plataforma» aponta para `/app/`. Essa versão web é servida à parte pelo servidor: não há pasta `app/` neste repositório.

Páginas: uma só (`index.html`) — início, funcionalidades, ecrãs, galeria, privacidade, descarregamento e perguntas frequentes.
